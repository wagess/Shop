# templates/

Un **template** est un squelette de document structuré que produit une task (contrairement à la checklist, qui *valide* un livrable déjà produit).

Vide pour l'instant. Candidats existants à évaluer avant migration :

- `docs/design.md`
- `docs/tokens.md`
- `PROJECT.md`

Ne migrer un template que lorsqu'une task doit explicitement le générer (CLAUDE.md §9).
